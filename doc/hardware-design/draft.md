# 离线 AI 陪伴玩具硬件原型开发与系统接线规范

**项目代号**：Project Peppa-Edge

**核心芯片**：Rockchip RK3566（Radxa ZERO 3W）

**计算架构**：ARMv8.2-A (4× Cortex-A55 @ 1.8GHz, 支持 `sdot` / `fp16`) + 0.8 TOPS NPU

**运行机制**：纯离线全双工对话（Sherpa-onnx + SHADOW-250M + Piper-TTS）

---

## 一、 系统架构设计

系统以极低延迟、零云端成本、高隐私保护为目标，全链路在本地端侧单板上完成自回归闭环：

## 三、 40-Pin GPIO 引脚连接对照表

Radxa ZERO 3W 排针与各模块引脚对接关系如下：

```
                          Radxa ZERO 3W (40-Pin Header)
                                         ┌──────────────┐
                         3.3V (Pin 1) ───┤ 1          2 ├─── 5V (Pin 2) ─────── 腮红 WS2812B 供电
       双 OLED SDA (I2C7_SDA / Pin 3) ───┤ 3          4 ├─── 5V (Pin 4) ─────── MAX98357A 功放供电
       双 OLED SCL (I2C7_SCL / Pin 5) ───┤ 5          6 ├─── GND (Pin 6) ────── 系统共地
       手部挤压按键 (GPIO3_C0 / Pin 7) ───┤ 7          8 ├─── UART2_TX
                                  GND ───┤ 9         10 ├─── UART2_RX
        I2S-BCLK (I2S1_SCLK / Pin 12) ───┤ 11        12 ├─── I2S-BCLK (麦克风 & 功放共用)
                                  ... ───┤ ...      ... ├─── ...
       腮红数据线 (SPI0_MOSI / Pin 19) ───┤ 19        20 ├─── GND
                                  ... ───┤ ...      ... ├─── ...
        I2S-LRCK (I2S1_LRCK / Pin 35) ───┤ 35        36 ├─── ...
```

| ---------------- | ------------- | ------------------------------------ | ---------------------- | ---------------------------------- |

|                  | `SCL`         | **Pin 5**                            | `GPIO0_B6 / I2C7_SCL`  |                                    |

## 四、 软件配置与编译优化规范



### 1. 宿主机 (Surface Laptop 7 WSL) 编译参数

针对 RK3566（Cortex-A55）全面开启 ARMv8.2-A 向量化与点积加速：

```cmake
# CMakeLists.txt 配置片段
set(CMAKE_CXX_STANDARD 20)
set(CMAKE_BUILD_TYPE Release)

add_compile_options(
    -mcpu=cortex-a55
    -march=armv8.2-a+dotprod+fp16
    -O3
    -ffast-math
    -funroll-loops
    -flto=thin
    -fPIC
)

```



### 2. 板端设备树插件启用 (Overlays)

在 Radxa OS 终端执行 `sudo rsetup`，在 **Overlays** 菜单中启用：

- `I2C7`（用于双眼 OLED）
- `I2S1`（用于麦克风录音与功放放音）
- `SPI0` 或对应 GPIO 输出（用于 WS2812B 腮红控制）

## 五、 状态机交互与视觉反馈定义

```
[ 用户按压手掌按键 (GPIO7=0) ]
        │
        ▼ (状态 1: 录音倾听) ──► 腮红绿灯常亮 ──► 眼睛呈现专注圆眼表情
[ 用户松开手掌 (GPIO7=1) ]
        │
        ▼ (状态 2: 思考生成) ──► 腮红黄灯快速流光 ──► 眼睛呈现向上转动/思考表情
[ LLM 首句截断送入 TTS ]
        │
        ▼ (状态 3: 佩奇说话) ──► 腮红粉灯随音量跳动 ──► 眼睛呈现微笑眨眼表情
[ 播音完毕 ]
        │
        ▼ (状态 0: 待机休眠) ──► 腮红蓝灯微弱慢呼吸 ──► 眼睛每隔 4 秒自然眨眼一次

```

## 六、 公仔装配与结构防坑指南

1. **双眼 OLED 透光处理**：

- 将两块屏幕用热熔胶固定在佩奇眼眶内衬处；
- 在屏幕外表面覆盖一层**浅粉色薄纱或微孔网布**，熄屏时与毛绒面料融为一体，点亮时表情清晰穿透。

1. **声学防回声与隔震**：

- 扬声器小音腔必须独立密闭，并在音腔边缘贴附 **1mm 厚 PORON 泡棉** 后固定在公仔嘴部，防止塑料共振杂音；
- INMP441 麦克风需套上专用**硅胶密封套**，拾音孔朝向公仔领口，与扬声器直线距离保持在 **50mm 以上**。

1. **主板散热与防短路**：

- 严禁用 PP 棉直接紧密包裹裸板；
- 建议使用 3D 打印镂空格栅骨架盒容纳 Radxa ZERO 3W 主板，贴附导热铝片，预留自然对流风道。
